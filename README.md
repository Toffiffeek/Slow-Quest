# 🌿 Slow Quest

**Slow Quest** is a 2D top-down RPG developed in Java as a student project. The game aims to encourage children to reflect on their digital media habits through a calm, exploration-based experience.

## 🎮 About the Project

The player explores a small game world, encounters characters, and gradually discovers the game's educational message. The project focuses on combining simple RPG mechanics with a thoughtful approach to digital well-being.

The goal is to create an accessible and engaging experience that encourages mindful use of games and digital media.

## ✨ Planned Features

* 🗺️ Top-down 2D world exploration
* 🚶 Player movement and collision detection
* 💬 NPC interactions and dialogue
* 📖 Educational quests and activities
* 🎨 Pixel-art-inspired visual style

*Features are planned and may change during development.*

## 🛠️ Technologies

* **Java**
* **Java Swing** — game window and rendering
* **IntelliJ IDEA** — development environment
* **Git & GitHub** — version control

## 🚀 Getting Started

### Requirements

* Java Development Kit (JDK)
* An IDE that supports Java, such as IntelliJ IDEA

### Running the Project

1. Clone or download this repository.
2. Open the project in your Java IDE.
3. Make sure the JDK is configured.
4. Run the `Main` class.

*Project setup may require adjustments depending on your IDE and Java configuration.*
